## Usage Instructions

### Manual Backup (from Instructions.txt)
```bash
# Create npm directory
mkdir npm

# Backup Node.js version
node -v > npm/node-version.txt

# Backup npm version
npm -v > npm/npm-version.txt

# Backup global packages (JSON)
npm list -g --depth=0 --json > npm/global-packages.json

# Backup global packages (text)
npm list -g --depth=0 > npm/global-npm-packages.txt
```

### Script Usage (Windows)
```powershell
# Backup Node.js version
.\backup-node.ps1

# Backup npm version
.\backup-npm.ps1

# Backup global packages
.\backup-npm-globals.ps1

# Restore npm version
```
