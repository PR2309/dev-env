~> Run restore file using this command:
    Command:
	powershell -ExecutionPolicy Bypass -File <pathOfFile>
    Example:
	powershell -ExecutionPolicy Bypass -File "./restore-vscode.ps1"

~> To backup vscode extensions:
    Step 0> (Restrore Backup)
        Install VS Code
        command (Powershell):
            Get-Content dev/vscode/extensions.txt | ForEach-Object { code --install-extension $_ }

    Step 1>
        Create a folder named "vscode" if not exists already.
        command:
            mkdir vscode
    Step 2> (Extensions backup)
        run the command:
            code --list-extensions > vscode/extensions.txt
        To backup all extensions
        To check the file (command):
            type vscode\extensions.txt

~> To backup vscode settings:
    Step 0> (Restrore Backup)
        Install VS Code
        command (Powershell):
            copy dev\vscode\settings.json $env:APPDATA\Code\User\

    Step 1>
        Create a folder named "vscode" if not exsists already
        command:
            mkdir vscode
    Step 2>
        To copy global settings.json of vscode
        run this command:
            copy "$env:APPDATA\Code\User\settings.json" vscode\settings.json

~> To backup vscode snippets:
    Step 0> (Restrore Backup)
        Install VS Code
        command (Powershell):
            copy dev\vscode\snippets\* $env:APPDATA\Code\User\snippets\

    Step 1>
        Create a folder named "vscode\snippets" if not exsists already
        command:
            mkdir vscode;
            mkdir vscode\snippets
    Step 2>
        To copy all .json snippets of vscode
        run this command:
            copy "$env:APPDATA\Code\User\snippets\*" vscode\snippets\

~> To backup vscode current working version in the system:
    Step 0> (Restore Backup)
        Install VS Code of same version manually from official site
            https://code.visualstudio.com/download
        OR run the restore script:
            - for Windows
                restore-vscode-version.ps1
            - for Linux / macOS:
                first make it executable using the command:
                    chmod +x restore-vscode-version.sh
                then run this file:
                    ./restore-vscode-version.sh

    Step 1>
        Create a folder named "vscode" if not exists already
        command:
            mkdir vscode
    Step 2>
        To copy vscode current working version in the system
        command:
            code --version > vscode/vscode-version.txt
